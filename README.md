# AgroNet 360 · AgroLogistics Global

Abre `index.html` con tu navegador para ver la web. Funciona sin instalación ni conexión a internet: todo (CSS, JavaScript e imagen de fondo) está dentro del archivo.

Contiene las secciones a–l del enunciado más un mini-quiz.

Elementos interactivos: menú fijo, matriz de riesgos 3×3, pestañas de fundamentación, topología SVG con componentes clicables, escenarios "Plan B", tablero de monitoreo con semáforo e incidentes simulados, simulador QoS (MOS + semáforo), calculadora de throughput VoIP, tarjetas que se voltean, lista de buenas prácticas, tabla comparativa con filtros, quiz con puntaje y modo claro/oscuro.

Los valores del tablero y del simulador son ilustrativos (Modelo E simplificado, ITU-T G.107).

`index-respaldo-v2.html` es la versión anterior; no hace falta entregarla.

Para verificar estructura y sintaxis: `node verificar.cjs`.
